Frontend Web Developer

We are looking for a Frontend Web Developer to build responsive, accessible, and high-performance web experiences. The role involves working closely with designers, backend engineers, and product teams to ship clean user interfaces for modern web applications.

Responsibilities:
- Build responsive web pages and reusable UI components using React, Next.js, TypeScript, HTML, and CSS
- Translate Figma designs into polished, production-ready interfaces
- Integrate frontend applications with REST APIs and JSON data
- Improve page performance, accessibility, and SEO
- Debug browser issues and maintain cross-browser compatibility
- Collaborate with backend engineers to define API contracts
- Write clean, maintainable code using Git and code review workflows

Requirements:
- Strong experience with React, Next.js, JavaScript, and TypeScript
- Solid understanding of HTML, CSS, responsive design, and accessibility
- Experience with Tailwind CSS or modern component styling systems
- Familiarity with REST APIs, Git, GitHub, and CI/CD workflows
- Ability to optimize Core Web Vitals and frontend performance
- Good communication skills and attention to detail

Nice to have:
- Experience with Node.js
- Experience with analytics, A/B testing, or SEO tools
- Familiarity with design systems and reusable component libraries
